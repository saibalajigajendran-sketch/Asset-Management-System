Application overview

Asset Management

A central workspace for browsing and maintaining organizational asset registers, with records connected to SharePoint.

What the application includes

Use the register navigation to move between asset types, find records, review their details, and manage records in the connected SharePoint lists. The available fields vary by register so each asset type can show relevant information.

Key features

01

Multiple asset registers

Browse 12 focused registers covering hardware, services, software, cloud resources, tracking, and intellectual property.

02

Search and status filtering

Find a register by name, or search its assets by name, ID, or assignee. Filter records by available status values and reset filters when needed.

03

Asset summaries and details

See a register’s total asset count and category-specific columns. Open a record to review its details and available service history.

04

Create and edit records

Add assets or update existing ones using fields provided by the selected SharePoint list. Field controls support choices, dates, numbers, and people where configured.

05

Delete with confirmation

Remove a record from its connected SharePoint list after reviewing a confirmation prompt.

06

CSV export

Export the currently selected register’s asset records to a CSV file for offline review or reporting.

07

Microsoft 365 people lookup

People fields can search the organization directory by employee name or email, helping select assignees and owners.

08

Status and lifecycle visibility

Display asset status, including active, in maintenance, in stock, allocated, and retired states when present in the records.

09

Paging and responsive layout

Move through large result sets with pagination. The interface adapts for narrower screens and includes accessible labels for controls and dialogs.

Typical workflow

  1. Choose a register from the left navigation or search for it.
  2. Search or filter the list to find the asset you need.
  3. Open the record to review its details, or choose Add asset or Edit asset to maintain it.
  4. Export the selected register to CSV when you need a local copy.
Data note: The application reads and writes asset records through configured SharePoint lists. The source code also contains sample records for demonstration, but the live register contents depend on the connected SharePoint environment and permissions.
